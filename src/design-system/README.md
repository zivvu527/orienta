# Orienta Design System Direction

This is a softer visual direction for Backpack in China / Orienta.

## Feeling

- A Japanese lifestyle magazine.
- A quiet travel notebook.
- A small city guide printed on cream paper.
- Warm, useful, human, and calm.
- Technology should feel invisible.

## Palette

- Background: `#F8F2E3`
- Surface: `#FFFDF7`
- Soft surface: `#F7EDC9`
- Cream yellow: `#F1DF9B`
- Ink: `#34352F`
- Secondary ink: `#77756B`
- Soft sage: `#7C8D7C`
- Travel clay: `#AD7F65`
- Emergency red: `#B84A3F`

## Typography

- Serif only for emotional page moments.
- Sans-serif for practical UI and all task content.
- Less boldness, more warmth.
- Avoid all-caps labels except for rare tiny utility marks.

## Component Language

- Cards should feel like guidebook notes, travel slips, and hotel stationery.
- Use soft tinted surfaces and fewer visible borders.
- Emergency actions stay clear and red.
- Buttons are quiet, tactile, and not tech-blue.
