# Legacy Hospital Scenario

This folder archives the earlier Hospital scenario prototype.

Hospital was removed from the active MVP because it is a higher-risk medical context and can involve safety, liability, diagnosis, treatment, and prescription concerns. The first release of Backpack in China focuses on lower-risk, high-frequency travel-in-the-moment tasks.

Archived scope:
- Urgent Help
- Describe Symptoms
- Allergies and Medication
- Registration Help
- Medical Communication Card
- Hospital Phrases
